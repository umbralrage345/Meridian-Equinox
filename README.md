Meridian is an educational space probe simulation where student teams guide an autonomous probe across four interconnected acts: exoplanet transit detection, telemetry fault identification, galaxy morphology classification, and lunar descent guidance. Decisions and accuracy in each act directly couple to mission conditions and resource penalties in subsequent acts, demonstrating end-to-end data science and machine learning workflows under mission constraints.

To run on Google Colab free tier, upload or clone the workshop repository, install the simulation package with `%pip install -e .`, and set `%env MERIDIAN_FAST=1` to enforce lightweight dataset sizes and execution budgets. Optional deep learning components in Act 3 automatically fallback to CPU-optimized scikit-learn models when running without GPU acceleration.

To run locally on standard student laptops running Windows, macOS, or Linux (Python 3.10-3.12, 4 GB free RAM, CPU only), clone this repository, create and activate a Python virtual environment, and install dependencies via `pip install -e .`. Validate your setup by running `pytest`, and launch your workshop notebooks using `jupyter lab` or `jupyter notebook`.
